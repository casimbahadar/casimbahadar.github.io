About me

I'm Casim, a solutions and application developer based in Kitchener-Waterloo, Ontario, and I run Phoenix Applications & Automations. I start from the problem, then work out what to build: a web app, an automation, a connection between tools, a report or a website. I care most about whether the result is easy to use for the people who have to use it every day.

I hold a BSc from the University of Waterloo and I'm studying Computer Programming and Analysis at Conestoga College. In fall 2026 I joined Conestoga's Gig Lab, a 15-week program for people starting freelance businesses.

Before development, I worked in insurance claims intake and in accounting and audit. Claims intake taught me how much depends on asking for the right details the first time. Audit taught me to check the numbers instead of trusting them. Both habits show up in how I build forms, checklists and training material.

Outside client work I design games. So far that includes a monster-catching RPG, a rhythm game that charts songs from audio, a tactics game six people can play across separate phones, and a Ludo game that families can play online from anywhere.

What I work with

HTML, CSS and JavaScript for the web, including the Web Audio API for sound. Supabase for databases, sign-in and data rules. Python for automation, Discord bots and scripts. Godot and C# for larger games. GitHub Pages for hosting.
