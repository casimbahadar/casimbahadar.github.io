Learning and tools

Courses and creative tools, built for people using them on a phone for the first time.

Step Through: Learn to Code

A programming course that runs on a phone with no internet connection. Learners write real code and watch it run one line at a time. Every lesson moves from reading, to predicting what a program will print, to writing it.

  • 48 lessons and 97 graded tasks
  • Nine languages from one set of lessons, including Python, JavaScript and C#
  • Prediction questions are generated from the program's own run, so the answer key can't be wrong
